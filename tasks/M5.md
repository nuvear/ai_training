# M5 — AI operations

**Goal:** the September-launch command from spec §7 works end to end.

## Scope
1. Copilot console (calm register) matching mock: chat, multi-step **plan preview** with tier badges, approval queue, ledger view.
2. Orchestrator: NL (EN/JA) → tool plan via Anthropic API tool-use against the internal registry; plan = parent `ai_action` with children.
3. Generative marketing: `landing.generate_variants` producing campaign-register pages per design §1.1 skeleton (hero statement, OUTLINE/VOICES/DETAILS/FLOW, repeated CTA); A/B weight reallocation with logged evidence; `campaign.draft_sequence` + approve-once scheduling.
4. Predictive ops: no-show and demand heuristics (simple logistic/threshold models over progress_event + orders — do not over-engineer), feeding reminders and `promo.suggest`.
5. Narrative analytics: `analytics.query` + `analytics.explain_change` over a safelisted semantic layer (named metrics/dimensions only — the model never writes raw SQL); `feedback.cluster`.
6. Semantic search over embeddings for participants/orgs/feedback.

## Exit criteria
- [ ] The full launch command ("Launch a 3-session Design Thinking cohort in September, ¥45,000, cap 30, early-bird 20% off until Aug 15") in BOTH languages produces the 5-step plan, executes auto steps, queues approve steps, and completes after approval
- [ ] Ledger shows parent plan + children with correct tiers
- [ ] analytics.query answers "why did sales dip" style questions with evidence rows, no raw SQL path (test)
