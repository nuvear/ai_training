# M1 — Workshop core

**Goal:** author a workshop in EN, localize to JA, publish it to a public catalog.

## Scope
1. Prisma models: workshop, cohort, session, content_item, skill, workshop_skill, waitlist_entry (`DATA_MODEL.md` §3) + lifecycle state machine per spec §3.
2. Domain services + tools: `workshop.*`, `cohort.*`, `session.update_agenda`, `waitlist.promote`, `content.generate`, `content.localize`, `content.mark_reviewed` (`COPILOT_TOOLS.md` §1–§2) — each with tier, zod schema, ledger write, tests.
3. Markdown content pipeline: remark/rehype + remark-wiki-link + sanitization; render `content/**/*.md`; paired `*.ja.md` resolution by locale; frontmatter parser.
4. Catalog importer: seed DB from `content/ideage/**` frontmatter (workshops, skills, levels).
5. Admin screens (calm register): workshop list/editor with bilingual fields + localization status chips; cohort scheduler.
6. Public catalog page matching `design/mock-screens.html` catalog tab, including "Led by Rajkumar Rajagobalan / 講師：ラジクマール・ラジャゴバラン" bylines.
7. Localization engine: Anthropic API call implementing register parameter (keigo_b2b/polite/casual); output flagged `ai_localized`.

## Exit criteria
- [ ] E2E: create workshop (EN) → `content.localize` → mark reviewed → publish → appears in public catalog in both locales
- [ ] Publishing without both locales fails with a typed error (test)
- [ ] IDEAGE seed content (if present in `content/`) appears in catalog
- [ ] Waitlist promotion honors 24h confirm window (test with fake timers)
