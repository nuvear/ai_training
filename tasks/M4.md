# M4 — Participant layer

**Goal:** a participant completes a cohort and holds a verifiable bilingual certificate.

## Scope
1. Models: enrollment, attendance, quiz*, certificate, progress_event, feedback (`DATA_MODEL.md` §5).
2. Participant dashboard (calm register) matching mock: progress, sessions, quiz score, certificate tile with signature line "Rajkumar Rajagobalan, Facilitator".
3. Attendance: facilitator check-off + self check-in token links.
4. Quiz engine: `quiz.generate` from actual `content/` materials → staff review → publish → attempts scored; completion rule evaluation (80% attendance + 70% quiz, per-workshop overrides).
5. Certificates: bilingual PDFs, `verify_code`, public verification page.
6. Nudges: scheduled personalized reminders honoring mute prefs; substitution-safe templates.
7. Public concierge chatbot with restricted toolset (`COPILOT_TOOLS.md` §7); self-identifies as AI; enrollment hands off to Airwallex.

## Exit criteria
- [ ] E2E: enroll → attend 3 sessions → pass quiz → certificate issued → verification URL validates
- [ ] Completion rule unit tests incl. per-workshop overrides
- [ ] Concierge cannot invoke any tool outside §7 (negative test)
