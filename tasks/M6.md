# M6 — Hardening & launch

**Goal:** go-live ready.

## Scope
1. Security pass: authz matrix test suite across all tools × roles; rate limiting on public endpoints; dependency audit; secrets scan.
2. Load: catalog/landing statically generated, LCP < 1.5s on throttled run; k6 or autocannon smoke on checkout API.
3. i18n QA: i18n-reviewer agent sweep over every user-facing string and template; flag anything not human-reviewed; ⚠ katakana spelling of the owner's name confirmed by owner.
4. Observability: structured logs, error tracking hook, AI-layer metrics (latency, approval rate, override rate) on a simple dashboard.
5. Ops runbook `docs/RUNBOOK.md`: deploy, rotate keys, restore backup, reconcile bank transfer, handle Airwallex webhook backlog.
6. Deploy: Vercel + Neon (CONFIRM with owner first — spec allows substitution); production env checklist; Airwallex live-mode cutover steps documented but executed by the owner.

## Exit criteria
- [ ] Full test suite green; authz matrix has zero unexpected allows
- [ ] Staging deploy reachable, both locales, all six mock-screen surfaces implemented and token-faithful
- [ ] Go-live checklist in RUNBOOK.md signed off by owner
