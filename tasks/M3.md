# M3 — Org portal

**Goal:** an org admin can buy 10 seats, assign 5 employees, and download an invoice.

## Scope
1. Org portal screens (calm register) matching mock: seat-pool KPIs, employee progress table, invoice list with PDF links.
2. Tools: `org.create`, `org.assign_seats`, seat-consuming `participant.enroll` (`COPILOT_TOOLS.md` §5).
3. Employee invitation flow (email, locale-aware, keigo register for B2B).
4. Privacy boundary from spec §2: org sees attendance/completion/quiz aggregates, never free-text reflections — enforced at query layer with a test.
5. Org monthly report generation job (`report.org_progress`): AI-written narrative, bilingual, PDF+HTML, authored-by line per design §2.1.

## Exit criteria
- [ ] E2E: org created → pool of 10 purchased (invoice path) → 5 employees assigned → dashboards correct → invoice PDF downloads
- [ ] Cross-org and reflection-privacy tests green
- [ ] Sample monthly report generated in JA passes the i18n-reviewer agent
