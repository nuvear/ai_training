# M0 — Foundation

**Goal:** a running skeleton where one toy copilot command executes end-to-end through the approval flow.

## Scope
1. Scaffold Next.js (App Router, TS, strict), ESLint/Prettier, Vitest, Playwright.
2. Prisma schema for identity + tenancy + `ai_action` ledger + `embedding` (from `docs/DATA_MODEL.md` §2, §7). Enable pgvector. Migrations run clean on a fresh DB.
3. Auth (email magic-link) + RBAC middleware for the four roles; RLS policies for org isolation.
4. i18n: next-intl with `en`/`ja` catalogs; `:lang()` line-height tokens; locale switcher preserving state.
5. Design token stylesheet from `DESIGN_GUIDELINES.md` §3–§6 (CSS variables, fonts, tategaki label component, tier badges).
6. Agent skeleton: server-side tool registry (name → handler, tier, zod input schema), `ai_action` write-before-execute, approval queue API + minimal UI.
7. One toy tool `workshop.ping` (tier: approve) wired through: copilot input → plan preview → approval → execution → ledger row.
8. Job queue running (a no-op scheduled job proves it).
9. Seed script stub + `.env.example` listing every secret with comments.

## Exit criteria
- [ ] `pnpm test` and `pnpm e2e` green in CI-like run
- [ ] Fresh clone → `pnpm i && pnpm db:migrate && pnpm dev` works with only `.env` filled
- [ ] Toy command demonstrably blocked without approval; executes after; ledger row present
- [ ] Org-isolation test proves cross-org read fails
- [ ] Locale toggle switches a sample page with correct JA typography tokens
